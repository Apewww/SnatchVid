# Variant: 02 — Warm & Friendly (Airbnb)

## Design stance
Ramah, hangat, mengundang — warna terang lembut dengan aksen merah cerah. Seperti ngajak ngobrol, bukan tool.

## Key choices
- Layout: satu kolom terpusat, kartu lembut dengan bayangan
- Typography: DM Sans (rounded, friendly geometric)
- Color: off-white `#faf9f7`, aksen coral `#ff385c` (Airbnb-like)
- Interaction: chip selector yang besar & jelas, progress bar, toast

## Trade-offs
- Strong at: paling welcome buat user awam. Hangat, nggak intimidasi.
- Weak at: kurang "premium/precision" buat power user.

## Best for
- User umum / non-teknis. Aplikasi yang mau terasa personal & bersahabat.
