# Variant: 03 — Bold Minimal Action-First (Vercel)

## Design stance
Hitam-putih tegas. Tanpa basa-basi — langsung ke fungsi inti: paste link → download. Vercel energy.

## Key choices
- Layout: satu kolom, paste-box dengan tombol inline di dalamnya
- Typography: Sora (geometric, bold)
- Color: monokrom `#0a0a0a` + putih, accent = putih solid
- Interaction: segmented control, tombol putih kontras tinggi, progress bar

## Trade-offs
- Strong at: paling action-first. User langsung tahu apa yang harus dilakukan. Kesan power-tool.
- Weak at: agak "dingin"/keras. Kurang warna buat yang suka hidup.

## Best for
- User yang mau cepat. Power user / developer. Aplikasi utility murni.
