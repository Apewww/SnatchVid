# Variant: 01 — Dark Minimal (Linear)

## Design stance
Precision engineering di atas kanvas hitam. Setiap elemen muncul dari kegelapan dengan hierarki luminansi halus — Linear signature.

## Key choices
- Layout: satu kolom terpusat
- Typography: Inter Variable dengan `cv01 ss03`, weight 510 khas Linear
- Color: near-black `#08090a`, satu-satunya warna aksen = indigo `#7170ff`
- Interaction: pill selector untuk kualitas & format, progress bar, toast

## Trade-offs
- Strong at: modern, profesional, "pro tool" vibe. Enak buat developer / power user.
- Weak at: mungkin terlalu gelap/kaku untuk user awam yang bukan tech-savvy

## Best for
- User yang suka tampilan tool developer yang sleek & presisi
